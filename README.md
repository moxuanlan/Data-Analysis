# DataLens

DataLens（暂定名）是一款面向个人和团队的数据分析网站，计划通过 Vibe Coding 开发，支持从数据导入到清洗、SQL 导出及可视化分析的工作流程。

> 当前处于需求评审阶段，本分支仅包含需求文档，尚未实现应用功能。

## 需求文档

- [Markdown 版需求文档](docs/数据分析平台-需求文档-v0.1.md)：在线阅读、评审和维护。
- [HTML 版需求文档](docs/DataLens-需求文档-v0.1.html)：下载后通过浏览器打开，支持目录导航、离线阅读和打印为 PDF。GitHub 文件页显示源码，不是在线演示站点。

## 规划功能

- **登录与共享**：个人账号访问及团队数据共享，团队身份和权限模式待确认。
- **数据导入双入口**：网页爬虫真实采集，或自行上传已有数据；上传格式暂建议 CSV、Excel，最终范围待确认。
- **数据展示**：统一数据集、分页查看、字段与来源信息展示。
- **数据清洗**：去重、补缺失值、格式统一、字段拆分合并、异常值识别；AI 提出建议，用户确认后执行。
- **MySQL SQL**：生成 CREATE TABLE、INSERT、SELECT、UPDATE，支持脚本预览与导出。
- **可视化分析**：根据数据和分析目的，从 17 类候选方案中推荐工具，交付参考代码或适配数据与操作指引。
- **AI 辅助**：计划接入用户指定的腾讯元宝 API 服务，实际接口及能力待核实。

## 首版范围

登录与数据隔离 → 选择爬虫或文件上传 → 查看数据集 → 生成并导出 MySQL SQL。

数据清洗与可视化建议分阶段交付；可视化分析不要求先生成 SQL。具体功能边界、验收标准及待确认事项以需求文档为准。
